# 📊 LeetCode SQL 50 Study Plan

A comprehensive collection of 50 essential SQL questions designed to build a strong foundation in database querying and crack SQL interviews. This repository contains my solutions to the **LeetCode SQL 50** study plan, covering everything from basic `SELECT` statements to advanced **Window Functions** and **Subqueries**.

## 📌 Project Objective
The primary goal of this repository is to track my progress and provide clean, optimized SQL solutions for the LeetCode SQL 50 track. It serves as a personal reference guide and a demonstration of my ability to solve complex data retrieval and manipulation problems using SQL.

## 🛠️ Technical Scope
- **Database Management System:** SQL (MySQL)
- **Core Concepts:** Filtering, Sorting, Aggregation, Joins (`INNER`, `LEFT`, `RIGHT`, `CROSS`)
- **Advanced Techniques:** Window Functions (`ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`, `LEAD()`, `LAG()`), Common Table Expressions (CTEs), Subqueries, Date Functions, and String Manipulations.

## 🚀 Setup & Execution

To test these queries locally:
1. **Choose an RDBMS:** Install a SQL environment (like MySQL Workbench).
2. **Setup Schema:** LeetCode problems provide SQL schema definitions. You can run those scripts to create the tables.
3. **Execute Queries:** Open the respective `.sql` file in this repository (e.g., `1633.sql`, `1934.sql`) and execute the query against your database.

> [!TIP]
> **Performance Optimization:** While solving these problems, the focus is not just on correct output, but also on query performance—ensuring optimal use of joins, avoiding unnecessary nested subqueries, and writing clean, readable code.
